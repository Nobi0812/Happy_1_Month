MONTHSARY WEBSITE

1. Open this folder in Visual Studio / VS Code.
2. Open each HTML file in your browser, or use Live Server.
3. Create the folder:
   images

4. Put your own photos inside images and rename them:
   photo1.jpg
   photo2.jpg
   photo3.jpg
   photo4.jpg
   photo5.jpg
   photo6.jpg

5. Edit the words inside the HTML files to personalize the website.

Pages:
Home      = index.html
Memories  = memories.html
Gallery   = gallery.html
Message   = message.html
Reasons   = reasons.html

If you use VS Code, installing the Live Server extension makes editing easier:
right-click index.html -> Open with Live Server.

The design is based on the uploaded TikTok reference: purple/black background,
five-page navigation, memories grid, 3D gallery, message card, reasons grid,
and floating hearts.
